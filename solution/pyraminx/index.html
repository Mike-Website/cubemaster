Méthode débutant

Résoudre un Pyraminx.

Aligne les pointes, complète une face triangulaire puis place les dernières arêtes.

  • Niveau : débutant
  • 4 étapes
  • Face jaune en haut

Sommaire

Avant de commencer1. Aligner les quatre pointes2. Former les sommets de la première face3. Placer les trois arêtes jaunes4. Terminer les trois dernières arêtesContrôle final

Avant de commencer

Le Pyraminx tourne autour de quatre sommets. Garde la même orientation pendant une formule : les sommets de gauche, de droite et du bas sont notés L, R et D. Une lettre seule indique un tiers de tour horaire en regardant le sommet concerné ; l’apostrophe indique le sens inverse. Les petites pointes se tournent séparément.

Ces lettres nomment les sommets que l’on tourne, pas les faces colorées. Les deux repères sont différents.

1. Aligner les quatre pointes

Tourne chaque petite pointe indépendamment pour que ses couleurs prolongent celles des pièces juste derrière elle. Cette manipulation ne déplace pas les arêtes.

2. Former les sommets de la première face

Choisis la face jaune comme première face et garde-la en haut. Oriente les trois grands sommets qui l’entourent jusqu’à voir le jaune sur cette face. Les arêtes peuvent encore être mélangées.

3. Placer les trois arêtes jaunes

Repère une arête contenant du jaune près du sommet du bas. Amène-la à l’avant avec D pour qu’elle se trouve sous son emplacement et vérifie sa deuxième couleur.

Dans la notation utilisée ici, F désigne la face avant et U la face jaune du haut. Si l’arête est à droite de l’avant (FR) et doit aller entre l’avant et le haut (FU), fais :

L D' L'

Si elle est à gauche (FL) et doit aller en FU, fais :

R' D R

Répète pour les trois arêtes. Si une arête jaune est déjà en haut mais mal placée, insère une autre arête à sa place pour la faire descendre, puis replace-la.

4. Terminer les trois dernières arêtes

Tourne le sommet du bas jusqu’à aligner ses couleurs avec les faces voisines. Il ne reste alors que trois arêtes. Compare leurs deux couleurs, puis choisis le cas correspondant ci-dessous.

  • Cycle FR → LF → RL → FR : R' D R D R' D R
  • Cycle inverse FR → RL → LF → FR : R' D' R D' R' D' R
  • Deux arêtes à retourner : D R D' L D' L' D R'
  • Cycle FR → FL → LR → FR : R L D L' D' R'
  • Cycle inverse FR → LR → FL → FR : R D L D' L' R'

Les positions FR, FL et LR désignent les arêtes entre les faces avant, droite et gauche. La face jaune reste en haut pendant tout le cas.

Ne retourne pas seulement une arête à la main : sur un Pyraminx standard, les arêtes retournées apparaissent par paires.

Contrôle final

Les quatre pointes prolongent les faces, les six arêtes relient les bonnes couleurs et chaque face triangulaire est unie.

Les cas de dernière couche suivent la méthode Pyraminx de Jaap Scherphuis, qui montre aussi les deux cycles complémentaires.
